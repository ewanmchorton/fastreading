# Fast Reading

Читалка для iPhone, работает как веб-приложение без сервера. Два режима:

- **Поток** — слова по одному в центре экрана. Опорная буква подсвечена, глазу не нужно прыгать по строке. Перед новой главой и после её названия — пауза около двух секунд.
- **Страница** — обычный текст, это же экран паузы. По умолчанию листается по страницам, в настройках можно выбрать прокрутку.
  - листание: тап по левой или правой трети — страница назад или вперёд, свайп тоже листает;
  - тап посередине (или любой тап в режиме прокрутки) — показать или скрыть панели; панели рисуются поверх текста, текст не сдвигается;
  - ▶ запускает поток с места остановки, а если страницу перелистнули — с первого слова страницы;
  - удержание пальца на слове — поток сразу стартует с этого слова.

Форматы: EPUB, FB2 (и `.fb2.zip`), PDF с текстовым слоем, TXT. Книги с DRM (купленные в Apple Books и других магазинах) и PDF-сканы открыть нельзя.

Книги и прогресс хранятся только на устройстве (IndexedDB), никуда не отправляются.

## Публикация на GitHub Pages

1. Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
2. Ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/fastreading/`.

## Установка на iPhone

1. Открой адрес в Safari.
2. «Поделиться» → «На экран „Домой“».
3. Запускай с иконки. Так приложение работает офлайн, и iOS не удаляет сохранённые книги.

## Устройство

Без сборки и зависимостей, обычные ES-модули:

- `js/app.js` — интерфейс, библиотека, режимы чтения;
- `js/parsers.js` — разбор EPUB, FB2, PDF, TXT;
- `js/zip.js` — распаковка архивов через встроенный `DecompressionStream`;
- `js/text.js` — разбиение на слова, опорная буква, длительность показа слова;
- `js/db.js` — хранение книг в IndexedDB;
- `sw.js` — офлайн-кэш.

Сторонние файлы: [pdf.js](https://github.com/mozilla/pdf.js) 4.10.38 (Apache 2.0) в `vendor/pdfjs`, шрифты Literata и Inter (SIL Open Font License) в `fonts`.

Проверки экрана чтения — в [`tests/`](tests/README.md).
